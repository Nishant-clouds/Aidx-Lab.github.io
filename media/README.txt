MEDIA FOLDER — AIDX Lab website (video only)
============================================

The Media section (07) shows one featured video plus a list of upcoming videos.

FEATURED VIDEO
  Save the file here as:  featured.mp4
  Until it's added the player shows the poster image but won't play.

ADDING MORE VIDEOS
1. Put the .mp4 file in this folder.
2. Open index.html and find the "07 MEDIA" section.
3. To swap the featured video, change <source src="media/featured.mp4">
   and the caption title and description.
4. The "Coming soon" list entries can be replaced with real titles.

FORMAT AND SIZE
  Use .mp4 (H.264) for all browsers.
  GitHub has a 100 MB per-file limit. For larger videos, upload to
  YouTube or OneDrive and embed or link it instead.
