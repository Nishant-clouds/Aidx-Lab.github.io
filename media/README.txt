MEDIA FOLDER
============
Drop recordings here. The site expects:

  project-walkthrough.mp4   -> video player in "06 — Media"
  team-update.mp3           -> audio player in the same section

Until added, players appear but won't play. Nothing else breaks.

TO ADD MORE
1. Put the file in this folder.
2. In index.html find the "06 — Media" section.
3. Copy a <figure class="mbox"> block, paste below, change the
   <source src="media/YOUR-FILE.mp4"> and caption text.

NOTE: GitHub has a 100 MB per-file limit.
